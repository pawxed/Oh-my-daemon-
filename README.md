# Oh My Daemon!
A personal list of daemon that I bootout cause iOS 16 is resource intensives for my iPhone 8! 

this daemon unloads unnecessary daemon using launchctl bootout that are hogging performance and battery life, it doesn't hurt to give it a try and I've tested this on my main iPhone! :o

if anything goes wrong, just force reboot or do userspace reboot and the daemon will run like normallt again
